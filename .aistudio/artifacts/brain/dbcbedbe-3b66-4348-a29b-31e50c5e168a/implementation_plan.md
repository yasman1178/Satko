# خطة بناء استوديو Mindplicit Studio لإنتاج الفيديوهات السيكولوجية

خطة معمارية وتنفيذية لبناء نظام متكامل لتحويل ملفات السيناريو الفصلي إلى فيديوهات يوتيوب احترافية طويلة (16:9)، مع ذاكرة خارجية دائمة، وتوليد وتحليل صوتي ذكي (Edge-TTS و Gemini AI)، ومعاينة فورية وتصدير مرن.

---

## مراجعة المستخدم والقرارات الحاسمة (User Review & Critical Decisions)

> [!IMPORTANT]
> تم تأكيد القرارات الرئيسية بناءً على إجاباتك:
> 1. **محرك الصوتيات الأساسي**: خادم Edge-TTS عالي الجودة مع طبقة كاش ذكية (Smart Cache) وقياس زمني دقيق للمدد لكل مشهد، مع إتاحة خيار Gemini TTS كبديل فائق الجودة.
> 2. **الذاكرة الخارجية للمشروع**: نظام تخزين متقدم داخل المتصفح عبر IndexedDB لحفظ الملفات الصوتية والصور والمشاهد محلياً دون فقدان، مع إمكانية تصدير واستيراد المشروع كملف JSON/ZIP.
> 3. **ملف الشابتر المرفق (`chapter_001.json`)**: توفير شاشة استيراد ذكية تتيح بضغطة زر تحميل ملف الفصل الأول فوراً أو استيراد أي ملفات فصول جديدة مع الفحص الآلي للبنية.
> 4. **اللغة والواجهة**: واجهة عربية كاملة (RTL) بطابع سينمائي داكن أنيق (Dark Baroque & Slate) يناسب محتوى السيكولوجيا والتوعية النفسية.

---

## 1. النظرة العامة والمفهوم الأساسي (Overview & Core Concept)

- **ماذا يقدم البرنامج**: استوديو إنتاج فيديو متكامل مبني على Next.js 15+ و Tailwind CSS، يأخذ ملف الـ JSON المصدّر من أبحاث أو NotebookLM، ويقوم بفحصه، وتوليد التعليق الصوتي لكل مشهد بالصوت المختار (`en-GB-RyanNeural`)، وربط الصور المولدة ومطابقتها، ثم بناء جدول زمني دقيق (Timeline) مع حركات الكاميرا (Zoom / Pan) والانتقالات، مع توليد حزمة نشر متكاملة لليوتيوب.
- **الذاكرة الخارجية والذكاء الاصطناعي (AI Smart Memory)**:
  - **تخزين IndexedDB**: حفظ نصوص المشاهد، وحالات التوليد، والملفات الصوتية كـ Blobs، والصور المرفوعة، والـ Metadata.
  - **تحليل البيانات بالذكاء الاصطناعي (Gemini 3.8 Flash)**: تحليل السرد الدرامي، واكتشاف فجوات الإيقاع أو الكلمات غير المتناسقة، واستخراج الكلمات المفتاحية وتحسين نصوص الصور (Image Prompts)، وتوليد حزمة النشر (العناوين الجذابة، الوصف الغني، التاجات الموجهة لليوتيوب، والتعليق المثبت).
- **الجمهور المستهدف**: صانع المحتوى التوعوي في مجالات علم النفس، الماكيافيلية، ولغة الجسد، الذي يحتاج لإنتاج فيديوهات طويلة (20-30 دقيقة) بدقة وجودة إنتاج سينمائية وبأقل جهد يدوي.

## 2. تجربة المستخدم والتصميم البصري (User Experience & Visual Design)

### مسار المستخدم الرئيسي (Key User Flows)

1. **الرئيسية واستيراد الشابتر**:
   - بطاقة بارزة جاهزة تتيح بضغطة واحدة: **"تحميل الفصل الأول (The Phantom Alteration - 33 مشهداً)"**.
   - منطقة سحب وإفلات لملفات JSON مخصصة مع فحص فوري للمخطط (Zod Validation).
2. **مركز الصوتيات (Audio Lab) - الأولوية القصوى**:
   - عرض قائمة المشاهد الـ 33 مع نص الإلقاء وزر استماع فوري.
   - زر "توليد كل الصوتيات دفعة واحدة" (Batch Generation) مع مؤشر تقدم حي ومؤقت زمني حقيقي.
   - إمكانية إعادة توليد أي مشهد منفرد، وتعديل سرعة الإلقاء (Rate / Pitch).
   - قياس مدة الصوت الفعلية لكل مشهد بالملي ثانية وتثبيتها في الذاكرة.
3. **مكتبة الصور والوسائط (Media Studio)**:
   - فحص جاهزية الصور الـ 33 ومطابقتها مع الحقول (`scene_001.png` حتى `scene_033.png`).
   - معاينة البرومبت المكتوب في الـ JSON وإمكانية نسخه لتوليد الصور في ImageFX أو Whisk.
   - رفع جماعي ذكي مع تقرير واضح عن الناقص والمكتمل.
4. **المحرر والجدول الزمني (Timeline & Preview)**:
   - شاشة عرض سينمائية 16:9 بنظام Canvas و Web Audio.
   - تطبيق مؤثرات الحركة (Zoom In, Zoom Out, Pan Left, Pan Right, Static) والانتقالات (Fade, Dissolve, Cut).
   - شريط زمني تفاعلي يضمن أن مدة كل مشهد مطابقة تماماً لمدة ملف الصوت الحقيقي + 0.2 ثانية.
   - ترجمة فورية متزامنة (Subtitles / Captions).
5. **المحلل الذكي والذاكرة (AI Memory & Analysis Hub)**:
   - لوحة تحليلات بالذكاء الاصطناعي تستعرض النبرة النفسية، وتوزيع الإيقاع، ومدى توافق النص مع الصورة.
   - تصدير واستيراد قاعدة بيانات المشروع كملف مضغوط (JSON / ZIP).
6. **حزمة النشر والتصدير (Publishing & Export)**:
   - خيارات العناوين الثلاثة، الوصف التفصيلي مع الفصول، الكلمات المفتاحية، برومبت الغلاف المصغر.
   - تصدير الفيديو بجودة 1080p / 720p عبر متصفح الويب.

### الهوية البصرية ونظام الألوان

- **النمط العام**: سينمائي داكن (Dark Baroque Slate) مستوحى من لوحات عصر النهضة والدراما السيكولوجية.
- **لوحة الألوان**:
  - خلفية عامة: رمادي فحمي فائق العمق (`#090D16` و `#0F172A`).
  - أسطح العمل والبطاقات: نغمات حجرية داكنة مع حدود خفيفة مريحة للعين (`border-slate-800`).
  - لون التمييز والنشاط: العنبر والذهب الباروكي المكتوم (`#D97706` و `#F59E0B`) وأزرق الإنجاز (`#3B82F6`).
- **الخطوط**: خطوط عربية حديثة واضحة ومقروءة (Tajawal / Plus Jakarta Sans) مع أرقام جدولية ثابتة (`tabular-nums`) لمنع الاهتزاز أثناء تشغيل الصوتيات والتايم لاين.

## 3. القرارات التقنية والمفاضلات (Key Product Decisions & Trade-Offs)

1. **محرك الصوتيات (Edge-TTS عبر Next.js API Route)**:
   - *الخيار*: خادم وسيط على Next.js يستدعي خدمات النطق عالية الدقة مع كاش تلقائي في IndexedDB.
   - *السبب*: صوت `en-GB-RyanNeural` واقعي جداً، رزين، ومثالي لفيديوهات التوعية والسيكولوجيا الماكيافيلية، دون تكلفة إضافية على المستخدم.
   - *البديل الاحتياطي*: توفير محرك Web Speech API و Gemini Flash-Lite TTS في حال انقطاع الشبكة.
2. **الذاكرة الخارجية المتطورة (Dexie / IndexedDB)**:
   - *الخيار*: قاعدة بيانات متصفح محلية متقدمة لتخزين ملفات الصوت Blobs والصور والنصوص وبيانات الـ Cache.
   - *السبب*: فيديوهات الـ 30 دقيقة تحتوي على عشرات الميجابايتات من الصوت والصور، والمتصفح يحتاج وصولاً فورياً بدون انتظار رفعها إلى خادم في كل مرة، مع الحفاظ على خصوصية بيانات المستخدم ومرونة حفظ واستئناف العمل بعد إغلاق المتصفح.
3. **محرك التوليد والعرض (Canvas + Web Audio + WebCodecs)**:
   - *الخيار*: تركيب الفيديو داخل المتصفح عبر WebCodecs مع شريط تقدم مباشر وحفظ للإطارات تدريجياً.
   - *السبب*: استهلاك ذاكرة منخفض وسرعة عالية وتوافقية ممتازة على المتصفحات الحديثة (Chrome / Edge).

### خريطة المكونات والوظائف (Component & Feature Mapping)

- `app/page.tsx`: لوحة التحكم والاستوديو الكاملة مع نظام تبويبات متناسق (المشروع، الصوتيات، الصور، التايم لاين، التحليل الذكي، التصدير).
- `app/api/tts/route.ts`: خادم توليد الصوتيات الذكي الذي يستقبل نص المشهد والصوت المطلوب ويعيد ملف الصوت WAV/MP3 مع المدة الزمنية بدقة.
- `app/api/ai/analyze/route.ts`: خادم استدعاء Gemini لتحليل بنية السرد وتوليد كلمات البحث والعناوين البديلة واكتشاف أي مشكلات في صياغة المشاهد.
- `lib/db.ts`: نظام إدارة الذاكرة الخارجية IndexedDB لتخزين المشاريع والمشاهد والملفات الثنائية (Audio & Images).
- `lib/chapter-sample.ts`: ملف الفصل الأول `chapter_001.json` مدمج ومتاح كخيار فوري للاستيراد بلمسة واحدة.
- `components/audio-lab.tsx`: شاشة إدارة وتوليد الصوتيات دفعة واحدة أو بشكل فردي مع الاستماع الفوري.
- `components/timeline-player.tsx`: مشغل تفاعلي 16:9 يعرض المؤثرات الحركية (Ken Burns Pan/Zoom) وانتقالات المشاهد ونصوص الترجمة.
- `components/ai-memory-panel.tsx`: شاشة التحليل الذكي وسجل الذاكرة الخارجية وتصدير حزمة العمل.
